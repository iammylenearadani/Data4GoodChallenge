# MSF On-Premises Document Vault & Spiderweb Visualization

A fast, low-footprint document retrieval tool designed for Doctors Without Borders (MSF) operating in low-connectivity crisis zones.

## Features
- **Local Search Engine:** Rapid semantic and metadata filtering.
- **Spiderweb Visualizer:** Graph visualization linking related protocols and documents.
- **On-Premises Ready:** Runs without requiring cloud access.

## Quickstart
```bash
npm install
npm run dev
